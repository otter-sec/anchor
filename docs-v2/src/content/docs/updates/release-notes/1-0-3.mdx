`1.0.3` is a patch on the `1.0` line that tightens dependencies between `anchor-*` crates so downstream workspaces pick compatible versions together (see [tighten inter-crate dependencies](#tighten-inter-crate-dependencies)). The same fix shipped on `1.1.2`.

---

## How to upgrade

To install the new `anchor-cli` via AVM:

```console
$ <blue>avm</blue> install 1.0.3
```

Or directly from the repository:

```console
$ <blue>cargo</blue> install <dim>--git</dim> https://github.com/otter-sec/anchor <dim>--tag</dim> v1.0.3 anchor-cli <dim>--locked</dim>
```

Then update Anchor crate(s) and TS package(s) to `1.0.3`.

## Recommended Solana version

The recommended Solana version is `3.1.10`, the same as [v1.0.0's recommended Solana version](./1-0-0#recommended-solana-version).

## Deps

### Tighten inter-crate dependencies

Version constraints between `anchor-*` crates are tighter so a mixed bump (for example updating `anchor-lang` without a matching `anchor-syn`) is less likely to compile against incompatible internals. Prefer upgrading the set together.
