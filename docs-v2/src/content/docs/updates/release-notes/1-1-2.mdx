`1.1.2` is a patch on the `1.1` line that tightens dependencies between `anchor-*` crates so downstream workspaces pick compatible versions together (see [tighten inter-crate dependencies](#tighten-inter-crate-dependencies)). The same fix shipped on `1.0.3`.

---

## How to upgrade

### Common steps

1. Update Anchor crate(s) to `1.1.2`.

2. Update TS package(s) to `1.1.2`.

To install the new `anchor-cli` via AVM:

```console
$ <blue>avm</blue> install 1.1.2
```

Or directly from the repository:

```console
$ <blue>cargo</blue> install <dim>--git</dim> https://github.com/otter-sec/anchor <dim>--tag</dim> v1.1.2 anchor-cli <dim>--locked</dim>
```

## Recommended Solana version

The recommended Solana version is `3.1.10`, unchanged from `1.1.1`.

## Deps

### Tighten inter-crate dependencies

Version constraints between `anchor-*` crates are tighter so a mixed bump is less likely to compile against incompatible internals. Prefer upgrading the set together.
