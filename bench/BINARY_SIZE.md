The changes are calculated by comparing the current results with the last version's results. Increase in size is shown with 🔴 and decrease is shown with 🟢.

> **Note**
> Results documented in this file are autogenerated. Running the benchmark updates them; manually editing the results should be avoided.

> **Warning**

### Notable changes

- lang: Use closures for `init` constraints to reduce the stack usage of `try_accounts`. Note that the binary size increase is exaggerated for the bench program because it uses unusual number of `init` constraints. Impact for normal programs will be a lot less severe. ([#2939](https://github.com/otter-sec/anchor/pull/2939)).
